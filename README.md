# Blockchain-Based Secure Digital Payment System

## Overview
A hybrid system combining Random Forest ML fraud detection 
with a simulated blockchain ledger for secure digital payments.

## Results
- Accuracy:  99.96%
- Precision: 98.70%
- Recall:    77.55%
- F1-Score:  86.86%
- Dataset:   284,807 real credit-card transactions
